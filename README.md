# Mock Interview Bot

## Setup (ek baar)

1. Server:
   cd server
   npm install
   .env.example ko copy karke `.env` banao aur apni API key daalo
   (key yahan se: https://console.anthropic.com)

2. Client:
   cd client
   npm install

## Run (do terminals)

Terminal 1:  cd server && npm start
Terminal 2:  cd client && npm run dev

Browser mein kholo: http://localhost:5173
